# Aramina Offline Technical Documentation

This fixed offline documentation site contains the Aramina and
XRD-preprocessing documentation, API/contract pages, and readable Python
source-code pages. It is a snapshot of the exact `main` commits recorded in
`bundle_manifest.json` and `site/source_manifest.json`.

No code is downloaded or updated when this site opens.

## Open on macOS or Linux

```bash
./start_docs.sh
```

## Open on Windows

```powershell
.\start_docs.ps1
```

Both launchers open `site/index.html` in the default browser. No Python,
Docker, internet connection, or local server is required to read this site.

The browser search covers contracts, technical documentation, and source file
paths. The `source/` directory also contains the raw, immutable source
snapshots for direct inspection.
