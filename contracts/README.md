# Aramina Output Contracts

This directory contains small filled YAML/CSV examples for files written by
Aramina. It is not a runtime output location.

Examples:

- [Prediction outputs](prediction/README.md)
- [Training outputs](training/README.md)

Canonical field definitions live under
[`docs/contracts/`](../docs/README.md#contracts). Actual run outputs are stored
beside their model or in the caller-selected output folder.
